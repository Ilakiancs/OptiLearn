# OptiLearn Desktop

Packages the OptiLearn web app as a native desktop application for Windows and macOS using Electron.

The web application (`optilearn/`) is **not modified** — Electron simply starts the FastAPI server as a background process and opens a native window pointing to `localhost:8000`.

---

## How it works

```
User double-clicks OptiLearn
  → Electron main process starts
  → Loading screen shown
  → FastAPI server spawned (bundled Python + optilearn source)
  → Polls localhost:8000 until ready (~5-10s)
  → Main window opens → full app
  → On close → server killed cleanly
```

Data (database, materials, uploads) is stored in the OS user data directory:
- **Mac**: `~/Library/Application Support/OptiLearn/`
- **Windows**: `%APPDATA%\OptiLearn\`

This means data persists across app updates.

---

## Development (test without building)

```bash
# Prerequisites: optilearn/.venv must exist (run optilearn/scripts/setup.sh first)
cd desktop
./scripts/dev.sh
```

Opens the Electron window using your local `.venv` — no bundling needed.

---

## Building installers

### Prerequisites

- Node.js 18+
- The `optilearn/.venv` must be fully set up (`./scripts/setup.sh` run)
- **Mac → Mac DMG**: run on a Mac
- **Windows → .exe**: run on Windows (or use GitHub Actions)
- ImageMagick (optional, for icon conversion): `brew install imagemagick`

### Build

```bash
cd desktop

# macOS DMG (run on Mac)
./scripts/build.sh --mac

# Windows NSIS installer (run on Windows)
./scripts/build.sh --win
```

Output lands in `desktop/dist-electron/`:
- `OptiLearn Setup 1.0.0.exe` — Windows NSIS installer
- `OptiLearn-1.0.0.dmg` — macOS disk image

### What gets bundled

- `optilearn/` source (app, frontend/dist, data/curriculum, scripts)
- `desktop/python-runtime/` — the full `.venv` copied in by `bundle_python.py`
- Electron runtime

The `.env` file (API keys) is **not** bundled. On first launch, if it exists in `optilearn/`, it is copied to the user data dir. Teachers configure their API keys there.

---

## First-launch experience

1. User installs and opens OptiLearn
2. Loading screen appears (~5-10s while server starts)
3. If no teacher account exists → `/setup` screen for first-time setup
4. Otherwise → student home screen

## Folder structure

```
desktop/
  electron/
    main.js          ← Electron main process (server spawn, window, tray)
    preload.js       ← Context bridge (minimal)
  scripts/
    build.sh         ← Build script (frontend + python bundle + electron-builder)
    bundle_python.py ← Copies .venv into python-runtime/
    dev.sh           ← Run in dev mode without building
  assets/
    icon.ico         ← Windows icon (copied from optilearn/)
    icon.icns        ← macOS icon (generated by build.sh)
    icon.png         ← PNG fallback
    icon-tray.png    ← System tray icon (22x22)
  package.json       ← Electron + electron-builder config
  python-runtime/    ← Generated by bundle_python.py (gitignored)
  dist-electron/     ← Build output (gitignored)
```
