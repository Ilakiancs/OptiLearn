# OptiLearn Desktop

Packages the OptiLearn web app as a native desktop application for Windows and macOS using Electron.

The web application (`optilearn/`) is **not modified** — Electron simply starts the FastAPI server as a background process and opens a native window pointing to `localhost:8000`.

---

## How it works

```
User double-clicks OptiLearn
  → First launch? → Setup wizard (API keys, Ollama, model download)
  → Loading screen shown
  → FastAPI server spawned (bundled Python + optilearn source)
  → Polls localhost:8000 until ready (~5-10s)
  → Main window opens → full app
  → On close → server killed cleanly
```

Data (database, materials, uploads) is stored in the OS user data directory:
- **Mac**: `~/Library/Application Support/OptiLearn/`
- **Windows**: `%APPDATA%\OptiLearn\`

This means data persists across app updates.

---

## First-launch experience

On the very first launch, a **setup wizard** guides the user through three steps:

**Step 1 — API Keys**
- Optional Gemini API key (enables cloud AI for richer responses)
- Optional Beyond Presence API key (enables AI avatar voice chat)
- Toggle for offline-only mode (skip keys entirely)
- Keys are saved to the user data directory, never bundled in the installer

**Step 2 — Ollama**
- App checks if Ollama is installed and running (`localhost:11434`)
- If missing: a button opens the Ollama download page for the right platform
- After installing, "Check again" re-verifies automatically

**Step 3 — AI Model Download**
- Choose Gemma 4 2B (~1.5 GB, recommended) or Gemma 4 4B (~2.5 GB)
- Progress bar streams live download output from `ollama pull`
- Can be skipped if a model is already installed

Setup only runs once. Subsequent launches go straight to the loading screen.

After setup, if no teacher account exists the app opens the `/setup` screen for account creation.

## What the tester needs

| Item | Bundled? | Notes |
|------|----------|-------|
| Python + dependencies | Yes | Bundled in `python-runtime/` |
| OptiLearn source + frontend | Yes | Bundled in `optilearn/` |
| Ollama | No | Setup wizard handles this |
| AI model | No | Setup wizard downloads it (~1.5 GB) |
| API keys | No | Setup wizard collects them on first launch |

The installer is **unsigned**, so:
- **Mac**: right-click → Open to bypass the Gatekeeper warning (one time only)
- **Windows**: click "More info" → "Run anyway" to bypass SmartScreen

## Development (test without building)

```bash
# Prerequisites: optilearn/.venv must exist (run optilearn/scripts/setup.sh first)
cd desktop
./scripts/dev.sh
```

Opens the Electron window using your local `.venv` — no bundling needed.

To re-trigger the setup wizard in dev, delete:
- **Mac**: `~/Library/Application Support/OptiLearn/.setup-done`
- **Windows**: `%APPDATA%\OptiLearn\.setup-done`

## Building installers

### Prerequisites

- Node.js 18+
- The `optilearn/.venv` must be fully set up (`./scripts/setup.sh` run)
- **Mac → Mac DMG**: run on a Mac (uses `/usr/bin/python3` for dmg-builder)
- **Windows → .exe**: run on Windows (or use GitHub Actions)
- ImageMagick (optional, for icon conversion): `brew install imagemagick`

### Build

```bash
cd desktop

# macOS DMG (run on Mac)
./scripts/build.sh --mac

# Windows NSIS installer (run on Windows)
./scripts/build.sh --win
```

Output lands in `desktop/dist-electron/`:
- `OptiLearn Setup 1.0.0.exe` — Windows NSIS installer
- `OptiLearn-1.0.0.dmg` — macOS disk image

### What gets bundled

- `optilearn/` source (app, frontend/dist, data/curriculum, scripts)
- `desktop/python-runtime/` — the full `.venv` copied in by `bundle_python.py`
- Electron runtime

The `.env` file (API keys) is **not** bundled. The setup wizard creates it in the user data directory on first launch.

## Folder structure

```
desktop/
  electron/
    main.js             ← Electron main process (setup wizard, server spawn, window, tray)
    preload.js          ← Context bridge for the main app window (minimal)
    preload-setup.js    ← IPC bridge for the setup wizard window
    setup.html          ← First-launch setup wizard UI
  scripts/
    build.sh            ← Build script (frontend + python bundle + electron-builder)
    bundle_python.py    ← Copies .venv into python-runtime/
    dev.sh              ← Run in dev mode without building
  assets/
    icon.ico            ← Windows icon (copied from optilearn/)
    icon.icns           ← macOS icon (generated by build.sh)
    icon.png            ← PNG fallback
    icon-tray.png       ← System tray icon (22x22)
  package.json          ← Electron + electron-builder config
  python-runtime/       ← Generated by bundle_python.py (gitignored)
  dist-electron/        ← Build output (gitignored)
```
